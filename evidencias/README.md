# Registro de Evidencias

## Criterio de nomenclatura
Los ficheros de salida y capturas se nombrarán siguiendo el patrón:
`s<NUM_SESION>-<descripcion-breve>.<extension>`

Ejemplos:
- `s01-estructura-local.png`
- `s02-red-ping.txt`

## Relación con la documentación
Cada evidencia que se suba a esta carpeta se enlazará desde la bitácora o memoria técnica con una breve explicación del resultado observado:
`![Descripción](../evidencias/capturas-o-salidas/sXX-nombre.png)`
